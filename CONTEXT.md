# Image Resizer

Графическое приложение для пакетного изменения размера изображений с сохранением корректной ориентации и пропорций.

## Language

### Ориентация

**Ориентация отображения** (Display orientation):
Как картинка выглядит для человека с учётом метаданных поворота — портрет или альбом.
_Avoid_: «повёрнутая картинка», ориентация пикселей

**Сырая ориентация** (Raw orientation):
Пиксельная сетка файла «как лежит в камере» — до применения метаданных поворота.
_Avoid_: реальный размер, физическая ориентация

**Метаданные поворота** (Rotation metadata):
Информация в файле о том, насколько нужно повернуть сырую ориентацию, чтобы получить ориентацию отображения.
_Avoid_: EXIF-тег (реализация), поворот

**Запечённая ориентация** (Baked orientation):
Состояние итогового файла: пиксели уже соответствуют ориентации отображения, метаданные поворота не нужны.
_Avoid_: исправленный поворот, нормализованная ориентация

### Размер

**Целевые размеры** (Target dimensions):
Размеры, которые пользователь задаёт для ориентации отображения, а не для сырых пикселей.

**Подпись размеров** (Dimensions suffix):
Часть имени выходного файла вида `_WxH`, соответствующая реальным размерам итогового файла.

### Цвет

**ICC-профиль**:
Метаданные цветового пространства, которые переносятся из оригинала в результат, чтобы цвета не сдвигались.
